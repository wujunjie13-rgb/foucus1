# 专注飞机 ✈️

专为难以专注的人设计的飞机客舱白噪音网站

## 简介

专注飞机是一个模拟飞机客舱声音的网站，旨在帮助您专注学习。通过选择目的地和预订航班，您可以设置专注时长，让飞机的白噪音帮助您集中注意力。

## 功能特点

- 🎧 **飞机客舱白噪音** - 模拟真实的飞机客舱环境音
- ⏱️ **目的地计时器** - 根据选择的目的地设定学习时长
- ⏸️ **暂停/继续** - 随时暂停和继续您的专注时光
- 🔊 **音量控制** - 调节白噪音音量至最舒适状态
- 🎨 **简洁黑色主题** - 优雅的深色界面，减少视觉干扰
- 📊 **进度追踪** - 实时显示剩余时间和完成进度

## 使用方法

1. **打开网站** - 在浏览器中打开 `index.html`
2. **选择目的地** - 从下拉菜单中选择一个目的地（决定学习时长）
   - 东京 - 15分钟
   - 首尔 - 25分钟
   - 新加坡 - 30分钟
   - 曼谷 - 45分钟
   - 悉尼 - 60分钟
   - 洛杉矶 - 90分钟
   - 纽约 - 120分钟
   - 伦敦 - 180分钟
3. **输入姓名** - 填写您的乘客姓名
4. **预订航班** - 点击"预订航班"按钮开始
5. **专注学习** - 享受飞机白噪音，专心学习
6. **控制音量** - 使用音量滑块调节声音大小
7. **暂停/继续** - 需要休息时可以暂停，准备好后继续
8. **结束航班** - 完成学习后点击"结束航班"查看统计

## 技术实现

- **纯HTML/CSS/JavaScript** - 无需任何框架或依赖
- **Web Audio API** - 实时生成白噪音
- **响应式设计** - 适配各种屏幕尺寸
- **现代浏览器支持** - Chrome, Firefox, Safari, Edge

## 本地运行

```bash
# 方法1：使用Python
python3 -m http.server 8000

# 方法2：使用Node.js
npx http-server

# 方法3：直接打开
# 在浏览器中打开 index.html 文件
```

然后访问 `http://localhost:8000`
